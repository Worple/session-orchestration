# Team memory

What a collaborator on any machine needs: decisions, pitfalls, conventions, reviewed by PR. Read this index before
your own project memory, then the topic file whose trigger matches your work, whole; your own memory uses the same
topic names and is the newer word where the two differ. Sessions never edit these files: tag a line `[team]` in your
own memory, and the coordinator's prune carries it here in a team PR (`session-status --init --team-memory`).
